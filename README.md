# Калькулятор интегралов

Консольное GUI-приложение на Python с использованием Tkinter для численного вычисления определённых интегралов, построения таблицы значений функции и экспорта результатов.

## Возможности

- Ввод произвольной математической функции `f(x)`.
- Поддержка математических функций: `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, `abs` и других.
- Использование констант `pi` и `e`.
- Задание границ интегрирования `[a, b]`.
- Настройка количества разбиений `N`.
- Выбор метода численного интегрирования:
  - Левые прямоугольники.
  - Правые прямоугольники.
  - Средние прямоугольники.
  - Метод трапеций.
- Отображение таблицы значений `x` и `f(x)`.
- Вывод результата интегрирования.
- Экспорт результатов в CSV и TXT.
- Проверка входных данных и обработка ошибок.

## Использование

1. Введите математическое выражение в поле `f(x)`.
2. Укажите нижнюю и верхнюю границы интегрирования `a` и `b`.
3. Задайте количество разбиений `N`.
4. Выберите метод интегрирования.
5. Нажмите **«Вычислить»**.
6. Просмотрите результат и таблицу значений.
7. При необходимости сохраните результаты в CSV или TXT.

### Пример

Входные данные:

| Параметр | Значение |
|---|---|
| Функция | `x**2` |
| Нижняя граница | `0` |
| Верхняя граница | `3` |
| Количество разбиений | `100` |
| Метод | Метод трапеций |

Математическое выражение:

$$
\int_0^3 x^2\,dx
$$

Точное значение:

$$
\boxed{9}
$$

Численный результат будет приближаться к точному значению при увеличении количества разбиений.

## Методы интегрирования

**Метод левых прямоугольников**

$$
I \approx h\sum_{i=0}^{N-1}f(a+ih)
$$

**Метод правых прямоугольников**

$$
I \approx h\sum_{i=1}^{N}f(a+ih)
$$

**Метод средних прямоугольников**

$$
I \approx h\sum_{i=0}^{N-1}
f\left(a+\left(i+\frac12\right)h\right)
$$

**Метод трапеций**

$$
I \approx h\left(
\frac{f(a)+f(b)}{2}
+\sum_{i=1}^{N-1}f(a+ih)
\right)
$$

Где:

- `I` — приближённое значение интеграла;
- `h = (b-a)/N` — шаг разбиения;
- `N` — количество разбиений;
- `f(x)` — подынтегральная функция.

## Безопасность

Математические выражения обрабатываются через модуль `ast` без использования `eval()`. Разрешены только определённые арифметические операции, константы и математические функции.
