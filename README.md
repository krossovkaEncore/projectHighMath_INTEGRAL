# Калькулятор интегралов

ООП-приложение на Python с графическим интерфейсом Tkinter для численного вычисления определённых интегралов, построения таблицы значений функции и экспорта результатов.

## Возможности

- Ввод произвольных математических выражений.
- Поддержка математических функций: `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, `abs` и других.
- Использование констант `pi` и `e`.
- Настройка границ интегрирования и количества разбиений.
- Четыре метода численного интегрирования:
  - Левые прямоугольники.
  - Правые прямоугольники.
  - Средние прямоугольники.
  - Метод трапеций.
- Отображение таблицы значений функции.
- Экспорт результатов в CSV и TXT.
- Проверка входных данных.
- Безопасный разбор выражений без `eval()`.

## Технологии

| Технология | Назначение |
|---|---|
| Python 3.10+ | Основной язык |
| Tkinter | Графический интерфейс |
| AST | Разбор математических выражений |
| Math | Математические вычисления |
| Dataclasses | Модели данных |
| Enum | Перечисление методов интегрирования |
| CSV | Экспорт результатов |

Дополнительные библиотеки не требуются.
